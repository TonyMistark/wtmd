# v0.11 — 一篇稿，一张桌子

**状态**：进行中（alpha）｜ 前置：v0.10.0 已发布（2026-10-19，详见 [V10_PLAN.md](V10_PLAN.md)）

## 一句话

v0.10 让书房能摆几张桌子。可同一篇稿子还能被两扇窗同时打开——两边各写各的，谁后落盘谁赢，另一边刚敲的字无声消失。v0.11 先把这条洞补上：**同一时刻，一篇稿子只在一扇窗里打开。**

## 现状（立项前核实）

- `DocumentStore.open(url:jumpingTo:)` 只看得见自己这扇窗：`url == fileURL` 才早退；别窗正开着同一篇，它不知道
- 多窗口之间只共享「怎么写字」的设置与账本（`SharedAppEnvironment`），没有共享「谁开着哪一篇」
- 写盘前的冲突检测（`detectExternalChange`）比的是 mtime：两扇窗交替保存时，后一扇会把前一扇的写入判成「外部修改」——那时字已经写完一遍，读者只剩两个坏选择
- 「同一篇文档在多扇窗口里同时编辑」写在 [V10_PLAN.md](V10_PLAN.md) 的边界里，是这一版要收的口

## alpha — 打开同一篇，就跳过去

- 新增 `OpenDocuments`（应用级一份，挂进 `SharedAppEnvironment`）：窗口 id ↔ 文档路径，比较一律走 `PathKey.canonical`（`/var` 与 `/private/var` 是同一个人）
- `WindowModel` 订阅 `store.$fileURL` 自动记账：打开、新建、另存为、外部改名跟随、文件消失，凡改 `fileURL` 的路径都自动覆盖——不靠每个入口记得登记一次
- `DocumentStore.open(url:jumpingTo:)` 加守门：这篇已经在本窗之外开着 → **不读盘、不切换**，改为把那个窗口带到前面；带 `JumpRequest` 时在那扇窗里落到行列（`⌘⇧F` 命中已开文档正是这条路）
- 关窗释放登记；主窗关闭（⌘W，应用还在）也要释放，重开时在窗口挂上那一刻补登记——否则「一篇稿还占着一张看不见的桌子」

## beta — 写盘兜底与恢复去重

- 另存为的目标文件正被另一扇窗写着 → 拦下来，别覆盖
- 启动恢复时同一篇被两扇窗记着（升级前的会话、手工改过的 defaults）→ 只留一扇，另一扇退回空白
- 兜底：即便绕过 UI（外部脚本、两扇窗都是升级前开的），写盘前发现「这篇在本应用另一扇窗里开着，且盘上的 mtime 比自己记的新」→ 转冲突副本，而不是直接覆盖

## rc — 收尾

- 文档、README、测试计数、发布

## 边界（这一版不做）

- 真正的协同：同一篇稿子两扇窗同时可视编辑。v0.11 只保证「不会两扇窗同时写同一篇」
- 会话移交：跳到那扇窗就是跳过去，不把它的内容搬过来
- 跨应用的文件锁（别家编辑器打开着这篇，仍然走既有的 mtime 冲突提示）

## 验收（alpha）

- [x] 主窗开着 A，⌘N 新窗再打开 A → 主窗到前面来，新窗仍是白纸
- [x] `⌘⇧F` 命中一篇已在别窗开着的文档 → 跳到那扇窗并落到命中行列
- [x] 关掉那扇窗再打开 A → 这次落在新窗
- [x] 两扇窗打开不同文件，互不打扰
- [x] 同一篇的两种路径拼法（符号链接解析前后）认作同一篇
- [x] 主窗 ⌘W 关掉后，副窗打开那篇不会被送到看不见的窗口

## 落地记录（alpha，2026-10-19）

- 新增 `OpenDocuments`（`Sources/wtmd/OpenDocuments.swift`）：窗口 id ↔ 文档路径，一律走 `PathKey.canonical`；挂进 `SharedAppEnvironment`，应用级一份
- 两个出口由 `WindowCoordinator` 接上：`reveal`（把占着它的窗口带到前面，必要时落到行列）与 `isReachable`（关掉的窗不算）
- 记账不靠每个入口手动登记：`WindowModel` 订阅 `store.$fileURL`（去重），打开、新建、另存为、外部改名跟随、文件消失全部自动覆盖
- 守门在 `DocumentStore.open(url:jumpingTo:)`，放在**读盘之前**：`handOver` 成功就直接返回，不重建预览、不改会话
- 主窗 ⌘W 关掉也要放掉登记——模型还留着（会话要留给下次启动），但窗口已经不在，不能把副窗的「打开」送到一扇看不见的窗里；重开时 `register` 补登记
- 测试 619 → **631**（新增 `OpenDocumentsTests` 12 条）
- 反向验证三组：去掉守门（`second.store.fileURL` 等 3 处红）/ 订阅还在但忘了记账（3 处红）/ 关窗不释放（`registeredWindows` 1 处红）

### 留给 beta

- 另存为落到另一扇窗正在写的文件，目前仍会覆盖
