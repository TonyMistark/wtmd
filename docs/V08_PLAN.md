# v0.8 — 笔要趁手

**状态**：进行中（2026-10-18 立项）｜ 前置：v0.7.0 已发布（2026-10-18，详见 [V07_PLAN.md](V07_PLAN.md)）

## 一句话

v0.7 把书房摆好了——树里能新建、能改名、能拖来拖去。可真正落笔的那块地方，从 v0.1 起就没怎么变过：
回车不会帮你续列表，粘贴网页带进来一堆乱码，写完一天也不知道自己到底写了多少。
v0.8 只做一件事：**让手在键盘上不用离开**。

## 现状（立项前核实）

- `EditorTextView` 没有重写 `doCommandBy`：回车、Tab 全走系统默认，`- item` 后回车就是空行
- 粘贴只拦了图片（`EditorTextPasteView.paste` → `ImageAssets.imagePNGData`）；从浏览器/Word 粘进来的富文本落到
  `isRichText = false` 的编辑器里，格式全丢，只剩一串硬换行
- 状态栏只有字数/词数/阅读时长的**当前值**，没有任何跨天的记录
- 语法高亮已有按行的列表/引用/围栏识别（`EditorTextView.highlight`），续行判断可以复用它认同一套规则

## P0-1 — 回车续行与 Tab 缩进（alpha）

新文件 `MarkdownEditing`：**纯函数**，不碰视图，单测直接喂字符串。

- **回车续行**：无序列表（`-` `*` `+`，保留缩进与空白宽度）、有序列表（编号 +1，保留 `.` 或 `)`）、
  任务列表（续 `- [ ] `，勾选清空）、引用（`> `，多层引用整串保留）
- **空项退出**：行里只有 marker（`- `、`1. `、`> `）时回车——把 marker 删掉，回到空行，不再多一行列表
- **不续的地方**：代码围栏内回车就是回车；表格行交给 beta
- **Tab / ⇧Tab**：有选区跨多行 → 整块缩进/反缩进；无选区 → 当前行缩进；缩进宽度两空格（GFM 嵌套列表的通行写法）
- 接线在 `EditorTextView` 的 `doCommandBy`；输入法组合中一律不拦（`hasMarkedText` 直接放行）

## P0-2 — 表格与粘贴（beta）

- **表格**：在表格行末回车 → 补一行同列数的空行（分隔行保持不动）；Tab / ⇧Tab 在单元格之间跳
- **智能粘贴**：粘贴板有 HTML / RTF 且没有图片 → 转成 Markdown 再插入
  - 覆盖：标题、粗体/斜体/删除线、行内代码、有序/无序/嵌套列表、链接、引用、代码块、表格、段落
  - 转换器 `HTMLToMarkdown` 同样是纯函数，单测喂 HTML 片段
  - 纯文本粘贴行为完全不变；图片粘贴仍走原有落地管线

## P0-3 — 字数目标与写作统计（rc）

- `WritingStats`：按日期记每日净增字数（defaults JSON，可注入，测试不碰真实数据）
- 状态栏显示「今日 1,240 / 800 字」；达成时进度条换强调色，不加弹窗、不加庆祝动画
- 设置里可设每日目标（默认关，设了才显示）
- 口径写清楚：**净增**（删字会扣），切文档与退出时结算，同一篇反复编辑不重复计

## 边界（这一版不做）

- 多光标、Vim 键位、Markdown 语法自动补全弹窗
- 拖放文字重排、块级拖拽
- 拼写检查（系统的那套与中文写作场景不匹配）
- 富文本所见即所得编辑（v0.4 已评估，结论不变）

## 验收

- [ ] 在各类列表/引用里回车，续行正确；空项回车退出列表；代码围栏内回车不受影响
- [ ] Tab / ⇧Tab 对单行与多行选区都正确，撤销一步回到原样
- [x] 表格里回车补行、Tab 跳格不破坏列结构
- [x] 从浏览器复制一段带标题与列表的内容粘进来，得到干净的 Markdown
- [ ] 每日净增字数统计准确（删字扣减、切文档结算），目标达成状态栏可见
- [ ] 既有不变式不破：高亮不替换字符、光标不跳文末、输入法可正常组合、查找替换与位置记忆全绿

## 进度日志

- 2026-10-18 **v0.8.0-alpha 完成**（issue #85）
  - 新文件 `MarkdownEditing`（纯函数）：`newline(in:selection:)` 算出「替换哪一段、换成什么」，
    `indent(in:selection:outdent:)` 管 Tab / ⇧Tab。`MarkdownEdit` 只描述一次编辑，不碰视图
  - 认的前缀：无序（保留 marker 字符与 marker 后的空白宽度）、有序（编号 +1，`.`/`)` 各自保留）、
    任务（续行一律回到未勾选）、引用（多层整串保留）、引用里套列表（两层前缀拼接）
  - **空项退出**：marker 之后没有内容时，回车把 marker 清掉、缩进留着——嵌套项退出后仍属父项；
    带选区时不走这条（读者的意思显然是拆行）
  - **不该续的地方**：围栏行本身、围栏内部、表格行、纯段落、行首
  - 缩进：多行选区整块替换并整块保持选中，连续 Tab 能继续往里推；空行不产生尾随空白；
    单行空行 Tab 插两空格而不是 `\t`
  - 接线在 `EditorTextView` 的 `doCommandBy`，一次 `insertText` 落地（撤销一步，先
    `breakUndoCoalescing`），高亮与光标行交给既有的 `textDidChange`；**输入法组合中一律放行**
  - **顺手修掉一个老 bug**：列表与引用的 marker 高亮用的是 `firstMatch` 返回的**行内偏移**，
    没加行首 base——以前只有文档第一行能染对，其余行都在染文档开头。新增
    `listMarkersOnLaterLinesAreColouredInPlace` 守住
  - 测试 390 → **425**（纯函数 24 + 编辑器链路 10 + 高亮回归 1）；反向验证四组：去掉空项退出、
    去掉围栏判断、回退高亮 base、去掉输入法守卫——对应用例全红（围栏那组第一次竟没红，
    暴露出用例光标落在文末空行、提前退出，已补强）

- 2026-10-18 **v0.8.0-beta 完成**（issue #87）
  - **表格**：`MarkdownEditing` 多认一种行——以 `|` 开头的表格行。回车在**当前行之后**补一行同列数空行
    （光标落第一格），带选区时仍交回系统（读者在选东西，不是在填表）；Tab / ⇧Tab 逐格走、跨行，
    最后一格再按 Tab 补行。分隔行不是落脚点：向前/向后找邻行时跳过 `| --- |`，表头 ⇧Tab 直接退到
    上一行的最后一格；分隔行上按 Tab 原地不动（不把 `---` 推成缩进行）
  - 列数按**未转义**的 `|` 数：`\|` 是单元格里的竖线。围栏里的 `|` 不是表格，Tab 在那里仍是缩进
  - 不猜列宽：空行写成 `|  |  |`——中日韩全角下按字符数硬凑必然歪，写得短反而整齐
  - **粘贴**：新文件 `HTMLToMarkdown`，手写解析器 + 渲染器（不引依赖，也不借 `NSAttributedString(html:)`——
    那条路要过 WebKit、只能主线程，还把标题层级压成字号，反推只能猜）。覆盖标题、段落、粗/斜/删除线、
    行内代码、有序/无序/嵌套列表、链接、图片、引用、围栏代码块（保留 `language-`）、表格、分隔线、硬换行；
    实体解码与空白压缩都在行内缓冲里做（行尾两个空格的硬换行由 `writeRaw` 绕开压缩）
  - RTF 只有 Word/备忘录才给：先用 AppKit 转 HTML，再走同一条路。纯文本与图片粘贴路径一字未动
  - 粘贴板可注入（`Coordinator.pasteboard`），测试用私有板，不碰用户的剪贴板
  - 测试 425 → **476**（表格 20 + HTML 26 + 粘贴链路 6，另删掉 alpha 里那条「表格行不动」的旧断言）；
