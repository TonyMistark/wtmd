# v0.12 — 写过的东西都在

**状态**：已发布（v0.12.0，2026-10-20）｜ 前置：v0.11.0 已发布（2026-10-19，详见 [V11_PLAN.md](V11_PLAN.md)）

## 一句话

自动保存保证「此刻不丢」。可读者昨天删掉的那三段、上周改坏的那一稿，盘上只剩最后一版。v0.12 补上另一半：**写过的每一版都留得住，翻得回去，取得回来。**

## 现状（立项前核实）

- 写盘路径只有三条：`persist`（防抖自动保存）、`save(to:)`（⌘S / 另存为）、`writeFile`（冲突里「保留我的修改」）。三条都只写「当前这一份」，写完旧内容就没了
- 冲突副本（`conflicts/`）只覆盖「磁盘被人改过」这一种情形，而且只在冲突未解决时产生；正常写作过程一版都不留
- 未命名草稿有草稿文件，但它只是「最新一版」，重启后覆盖即消失
- Time Machine 是系统级的、按小时的，且默认不保证给 `~/Documents` 之外的临时改动留点

## 形态

**本地、纯文本、不进用户的文件夹。**

- 存放在 `~/Library/Application Support/wtmd/history/<路径哈希>/`，每个版本一个普通 `.md` 文件，文件名带时间戳与内容哈希
- 旁边一份 `meta.json` 记「原来是哪一篇」（路径 + 文件名）——历史目录要能被人直接用 Finder 打开翻，不能只有哈希
- 不写到稿子旁边：读者把文件夹拷给别人、丢进 Git 仓库时，不该带着一屋子旧版本

## alpha — 先把旧的留下来

- 新增 `DocumentHistory`（应用级一份，挂进 `SharedAppEnvironment`）：
  - `capture(_:for:force:)`：内容与最新一版相同就跳过；距上一版不足 `minimumInterval`（5 分钟）跳过；`force` 越过间隔
  - `entries(for:)` / `content(of:)` / `removeAll(for:)`：全部从目录本身推导，不另立索引——账本会和文件走散，目录不会
  - 保留策略：每篇最多 50 版、最多 30 天，超出即清（在每次留存后顺手做）
- 接线三个时刻：
  - **打开时**（`DocumentStore.open` 读到盘之后）：留一版「打开时的样子」，`force`
  - **每次真正写盘后**（`writeFile` / `save(to:)`）：按 5 分钟间隔留一版
  - **离开时**（`flushPendingSave` 写完之后）：`force` 留一版——切文档、关窗、退出都走这里，「这次写到哪儿」不会因为间隔没到而漏掉
- 未命名文档不记账：草稿目录本身就是它的一版，且没有稳定身份
- 路径比较一律 `PathKey.canonical`：`/var` 与 `/private/var` 是同一篇，历史也是同一份

## beta — 翻得回去，取得回来

- 「版本历史」面板：左边按时间倒序列出（今天 / 昨天 / 更早分组），右边只读预览选中的那一版
- 恢复：**先把当前这一版留一份**，再把这版装回编辑器；不直接写盘，走自动保存那条路，冲突与多窗占用的三道口照旧
- 删除单版 / 清除这篇的全部历史；面板里说清「存在哪里、留多少」
- 入口：菜单 `文件 › 版本历史…` + `⌘K` 命令面板；不用工具栏按钮（写作时不需要它）

## rc — 收尾

## 边界（这一版不做）

- 云端 / 跨设备历史：这是本地工具，历史也只在本机
- 逐字符 diff 与合并：版本是整份的，选择就是「用这一版」；真正的合并属于协同，仍不做
- Time Machine 集成、版本自动清理的设置项：先按固定口径跑一段，需要再开口子
- 未命名草稿的历史：草稿只有一个，重启即覆盖，没有可比较的过去

## 验收（alpha）

- [x] 打开一篇已有文件 → 历史里多一版，内容与盘上一致
- [x] 同一篇再打开一次（内容没变）→ 不重复留
- [x] 编辑后自动保存 → 距上一版超过间隔才留新版
- [x] 编辑后立刻切走 / 关窗 → 最后这一版仍被留下（`force`）
- [x] 内容清空 → 不留空版本（旧的那几版还在）
- [x] 超过 50 版 / 30 天 → 旧的自动清掉，新的留着
- [x] 同一目录下的两篇同名文件（不同文件夹）→ 各自的历史互不混
- [x] 同一篇的两种路径拼法 → 同一份历史
- [x] 未命名文档 → 不产生历史目录

## 落地记录（alpha，2026-10-19）

- 新增 `DocumentHistory`：目录 = `<路径哈希>/<时间戳>-<内容哈希>.md` + `meta.json`。
  列表全部从目录推导，不另立索引——账本会和文件走散，目录不会。
- 三个留存时刻：`open` 读到盘之后（`force`）、`writeFile` 写盘之后（按 5 分钟间隔）、
  `flushPendingSave` 写完（`force`）。**写盘收成一条路**：`save(to:)` 原来自己
  `try text.write`，现在改走 `writeFile`（返回 `Error?`，好让 ⌘S 的失败提示还能说出原因）。
- 去重：内容与最新一版相同就不留；间隔内的普通写盘跳过；`force` 越过间隔。
  进程内再记一张 `lastCapture` 表，省掉「每次自动保存都去列目录读上一版」那趟白跑。
- 保留：每篇 50 版、30 天，留存后顺手清。
- 未命名稿不记账：草稿目录自己就是它的一版，且没有稳定身份。
- 测试 637 → **654**（`DocumentHistoryTests` 12 条 + `HistoryCaptureTests` 5 条）。
  四个窗口脚手架补注入临时历史目录，测试不碰真实 `~/Library/Application Support/wtmd/history`。
- 反向验证六组全红：去掉去重（4 处）/ 去掉间隔（5 处）/ 不清理旧版（6 处）/
  打开时不留（8 处）/ 写盘时不留（9 处）/ 离开不强制（4 处）。

### beta 接手时的清单

- 面板：左侧按时间倒序列出（今天 / 昨天 / 更早），右侧只读预览
- 恢复时要**先把当前这一版留一份**再装回去；装回走编辑器的 `text`，写盘交给自动保存
  （冲突与多窗占用那三道口照旧）
- `DocumentHistory` 目前不是 `ObservableObject`：面板要「存完立刻看得见」就得加
  `revision` 广播（照 `ConflictArchive` 的样子）

## 落地记录（beta，2026-10-19）

- `DocumentHistory` 变 `ObservableObject`，`revision` 计数：`capture` / `remove` /
  `removeAll` 各 +1，**跳过时不广播**（自动保存每 1.2 秒一次，抖面板没法看）。
- `DocumentStore` 暴露 `historyEntries`（当前这篇，最新在前）、`historyVisible`、
  `historyFolder`、`canBrowseHistory`；订阅两件事：`history.objectWillChange`（本窗
  与别窗的留存/删除）与自己的 `$fileURL`（换文档换清单）。
  **坑**：`@Published` 在 `willSet` 里发——sink 里必须用发出来的那个值，
  读 `self.fileURL` 拿到的还是上一篇。
- `restoreHistory`：先把当前版 `capture(force: true)`，再装回编辑器；
  `fileURL` 不动（还是这篇，不是另存为一篇）；`documentEpoch` 前进一代——
  一次恢复不该在字数账本里算成「今天删了几千字」；写盘走 `scheduleSave`，
  冲突与多窗占用那三道口照旧。
- `HistoryPanel`（新）：左列表（`HistoryGroup.sections` 按 今天/昨天/更早 分堆，
  纯函数可测）、右只读源码预览（可选中复制）、底栏「在访达中打开 / 清空全部历史 /
  删除 / 装回这一版 / 关闭」。删除与清空都有确认对话框。
  行首时间：今天只报时刻，往前带日期——「更早」堆里光一个 22:41 说不上是哪天。
- 入口：命令目录新增 `.showHistory`（⌘Y），菜单 `文件 › 版本历史…` + ⌘K 面板；
  未命名草稿灰着（它没有稳定身份），有名但还没历史时可点——面板自己会解释。
- **顺带修了一处排序歧义**（alpha 遗留）：同一秒可能落下两版（打开时 + 紧接着离开），
  文件名只到秒，只比名字的话谁在上面全看内容哈希。排序补第三把钥匙：创建时间
  （`attributesOfItem` 的 `creationDate`，文件系统给的，细于秒）。
- 测试 654 → **665**（`HistoryPanelTests` 10 条 + 广播 1 条）。面板版式用
  `NSHostingView` + `cacheDisplay` 渲染成图核对过（临时探针，用完即删）。
- 反向验证六组全红：恢复前不留当前版 / 恢复变成另存一篇 / 不订阅历史广播 /
  换文档读到上一篇 / 打开面板不刷新 / `capture` 不广播。
